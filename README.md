# 🎬 GLASSY CINEMA

### 3D Interactive Movie Collection

**36 Movies. 6 Collections. One Cinematic Experience.**

A modern, visually immersive movie showcase built with **HTML5, CSS3, and JavaScript**, featuring interactive 3D movie cards, cinematic transitions, glassmorphism effects, and a responsive browsing experience.

Glassy Cinema transforms a traditional movie catalog into a visually engaging digital experience inspired by modern streaming interfaces and cinematic design.

---

## 🌟 Project Overview

Glassy Cinema is a frontend web development project focused on creating an interactive, visually rich movie exploration interface.

Instead of displaying movies in a conventional static grid, the website introduces a cinematic experience through three-dimensional card transformations, smooth scrolling, interactive galleries, and carefully designed visual effects.

The project combines modern interface design with practical frontend development techniques to demonstrate how motion, depth, and visual storytelling can improve digital experiences.

### 🎯 Project Objectives

- Create a premium cinematic user interface.
- Implement smooth, interactive 3D movie animations.
- Organize 36 movies into six curated collections.
- Deliver a responsive experience across mobile and desktop devices.
- Demonstrate modern glassmorphism and CSS animation techniques.
- Build an interactive experience using frontend web technologies.

## 🚀 Getting Started

Glassy Cinema is designed as a frontend-focused web project.

### Prerequisites

You need:

- A modern web browser such as Chrome, Edge, Firefox, or Safari.
- A code editor such as Visual Studio Code (recommended).
- A local web server for development (recommended).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/glassy-cinema-3d-movie-collection.git
```

**2. Open the project directory**

```bash
cd glassy-cinema-3d-movie-collection
```

**3. Start a local development server**

Using Python:

```bash
python -m http.server 8000
```

**4. Open the website**

Visit:

```text
http://localhost:8000
```

Alternatively, open the project's main HTML file in a browser. A local server is recommended for consistent behavior.

## 🌐 Deployment

The project can be hosted using static website hosting services, including:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

### Deploy with GitHub Pages

1. Upload the website files to your GitHub repository.
2. Make sure `index.html` is located at the published site root.
3. Open your repository's **Settings**.
4. Navigate to **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` directory.
7. Save your settings and wait for deployment.

Your website will normally be available at:

```text
https://YOUR_USERNAME.github.io/glassy-cinema-3d-movie-collection/
```

Replace `YOUR_USERNAME` with your GitHub username.

## 🎨 Design Philosophy

Glassy Cinema follows a design philosophy built around three principles.

**Immersion**

The interface should feel cinematic rather than conventional. Each interaction contributes to a visually engaging movie discovery experience.

**Motion**

Animation is used to guide attention, establish visual hierarchy, and create smooth transitions between content.

**Simplicity**

Despite its visual complexity, the website aims to maintain straightforward navigation and intuitive controls.

The result is a premium-looking movie showcase that combines functionality with visual storytelling.

## 🧩 Project Architecture

The website is organized around several major interface components.

| Component         | Function                                            |
| ----------------- | --------------------------------------------------- |
| Hero Showcase     | Presents featured movies using cinematic 3D visuals |
| Movie Collections | Displays movies grouped by category                 |
| Movie Cards       | Presents artwork and movie information              |
| Movie Details     | Shows information about selected movies             |
| Search Interface  | Helps users find films                              |
| Watchlist         | Allows users to manage selected movies              |
| Responsive Layout | Adapts the interface to different devices           |

The project is a movie showcase, not a video-streaming service. It does not provide movie playback or access to copyrighted film streams.
